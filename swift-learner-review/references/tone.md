# Tone for adult learners

Most learners are working adults. They are beginners at Swift, not children. Write as a senior colleague, not a teacher.

## Avoid (classroom voice)

| Japanese | English equivalent |
|---|---|
| 〜しよう / 〜ましょう | Let's … |
| 癖をつけよう | Make it a habit |
| 今のうちから / 早いうちに | While you're still early |
| 引き続き頑張りましょう | Keep up the good work! |
| 〜を身につけよう | You should learn to … |
| 試してみよう（命令調） | Go try it |

## Use instead (peer voice)

| Japanese | English equivalent |
|---|---|
| 〜がおすすめです | I'd recommend … |
| 〜という書き方が一般的です | The common way is … |
| 〜という選択肢もあります | Another option is … |
| 検討してみてください | Worth considering |
| 〜が伝わってきます | It's clear that you … |
| 規模が大きくなる前に〜しておくと | Before this grows, … |

## Principles
- **Recognition over encouragement.** "The comparison in your reflection is precise" beats "keep going!". Recognition is about what they did; encouragement is about what you want them to feel.
- **Offer, don't instruct.** "〜がおすすめ" lets the learner choose; "〜しよう" tells them to obey. Choosing is how they learn judgment.
- **Facts, not verdicts on the person.** "This `!` will crash when the text is empty" — not "you're being careless".
- **Warm is fine.** Emoji (👍 ✨ 🎯) and soft endings (〜ですね) are welcome. Adult tone is not cold tone.
- **Direct about failure.** A ❌ stays a ❌. Softening it into "almost!" wastes the learner's time.
